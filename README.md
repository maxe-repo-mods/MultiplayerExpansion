# MultiplayerExpansion

Removes the player limit and enables late joining mid-run with full state sync.

R.E.P.O. BepInEx mod. Host-side only.

## Install

Requires [BepInEx 5.x](https://thunderstore.io/c/repo/p/BepInEx/BepInExPack/).

Place `MultiplayerExpansion.dll` in `BepInEx/plugins/`.

## Configuration

Edit `BepInEx/config/maxenterme.MultiplayerExpansion.cfg` after first launch.

## Build

```
dotnet build -c Release
```
